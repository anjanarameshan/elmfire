Ember landings on non-burnable building cells (2026-11-13)

Question: with buildings that cannot burn (as in Theodori et al. 2026), how many embers land on each building cell?

Main run: nobldg/spot2, 10 seeds, 16 h, spot fire 2 (inputs = ms_st09/spot2/inputs).
  Same as ms_st09 (PER-MW generation, EMPIRICAL distance, EULERIAN accumulation, PHYSICAL ignition, default ember
  yields) except USE_BLDG_SPREAD_MODEL = .FALSE. (env BLDG_SPREAD=.FALSE. in scripts/run_wui_case.sh).
  Run: ember_count/run.sh  (each seed < 1 min). Check: 0 of 28,060 building cells burned in seed 1.
  Burned area (acres) by seed: 6693, 781, 6229, 3903, 7342, 5645, 3080, 789, 3167, 1124
  (ms_st09 with burning buildings: 26,579 in seed 1).

ember_flux.tif = embers landed per 30 m cell, summed over the run (raw grid written as is, elmfire_io.f90 ~3072;
the ignition code divides it by dx^2 to get embers/m2, elmfire_spotting.f90:909). Landings are added on every cell
whatever its fuel (elmfire_spotting.f90 ~725), so building cells get a count although they never burn.
Ember load (g/m2) = ember_flux x 0.2 g / 900 m2.

Analysis: python scripts/ember_count_check.py ember_count/nobldg/spot2  -> nobldg/spot2/ember_count_by_building.csv
  per building (vulnerability/features.csv points, label y_A): p_arrival (share of runs where a neighbour cell
  burned), p_ember (share of runs with >= 1 landing), mean_all, mean_nonzero (runs with landings only, as Theodori),
  max, ember_load_g_m2.

Reading: without house-to-house spread the fire reaches fewer buildings, and the landing count barely separates
destroyed from not destroyed; 33% of buildings with no embers in any run were destroyed (zero-exposure problem).

Tried first and dropped (folders spot2, spot2_flin0, spot2_all; scripts/run_ember_count.sh): the older superseded
spotting model with Theodori's settings (1-2 % crown / 0.1-1 % surface cells above 1000 kW/m throw 1-5 embers,
PIGN 100 %, guide p. 31-32 lognormal distances). Gatlinburg fire intensity on burned cells is median 15, max 55 kW/m,
so no cell passes 1000 kW/m; even with threshold 0 and 100 % of cells spotting, the fire reached only 25-102 acres
because embers land tens of metres away. Those settings do not carry the Gatlinburg fire.

Embers GENERATED by vegetation around each building (2026-11-13): scripts/ember_generation_near_buildings.py
  -> nobldg/<location>/ember_generation_near_buildings.csv and nobldg/ember_generation_near_buildings.csv (50 runs).
ELMFIRE has no per-cell generation output for the Eulerian model (DUMP_SPOTTING_OUTPUTS is Lagrangian only, guide
1.11.8), so it is computed from the PER-MW rule: FLIN x 30 m x 33.3/1000 embers/s for TAU_EMBERGEN = 10 s after the
cell's arrival time, i.e. ~10 x FLIN (kW/m) embers per burning vegetation cell (intended amount).
Check: total embers landed / intended generated = 0.26-0.53 per run (spot2, E1km, W1km seeds 1-2). Emission is only
counted over the overlap of the 10 s window with the model time steps (elmfire_level_set.f90 ~1271, DT up to 30 s),
so realised generation is lower than intended; flin output is surface + canopy, generation uses surface only.
